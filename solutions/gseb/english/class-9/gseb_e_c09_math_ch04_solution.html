Solved ExamplesEquations and ordered-pair solutions

📋 Given
Write each equation in the form \(ax+by+c=0\) and indicate \(a,b,c\):
(i) \(2x+3y=4.37\); (ii) \(x-4=\sqrt3\,y\); (iii) \(4=5x-3y\); (iv) \(2x=y\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Transpose every term to the left side and compare with \(ax+by+c=0\).
✏️ Step-by-Step Solution
  1. (i) \(2x+3y-4.37=0\): \(a=2,b=3,c=-4.37\).
  2. (ii) \(x-\sqrt3y-4=0\): \(a=1,b=-\sqrt3,c=-4\).
  3. (iii) \(5x-3y-4=0\): \(a=5,b=-3,c=-4\).
  4. (iv) \(2x-y=0\): \(a=2,b=-1,c=0\).
✅ Final Answer
The four standard forms and coefficients are shown above.
🌐 Gujarati Translation — Final Answer
ચારેય સમીકરણોના પ્રમાણભૂત સ્વરૂપ અને ગુણાંકો ઉપર દર્શાવ્યા છે.
📋 Given
Write each as a linear equation in two variables by introducing the missing variable:
(i) \(x=-5\); (ii) \(y=2\); (iii) \(2x=3\); (iv) \(5y=2\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
A one-variable linear equation can be written in two variables by assigning coefficient \(0\) to the missing variable.
✏️ Step-by-Step Solution
  1. (i) \(x+0y+5=0\).
  2. (ii) \(0x+y-2=0\).
  3. (iii) \(2x+0y-3=0\).
  4. (iv) \(0x+5y-2=0\).
✅ Final Answer
The required two-variable forms are \(x+0y+5=0\), \(0x+y-2=0\), \(2x+0y-3=0\), \(0x+5y-2=0\).
🌐 Gujarati Translation — Final Answer
આવશ્યક બે ચલવાળા સ્વરૂપો ઉપર દર્શાવ્યા છે.
📋 Given
Find four different solutions of the equation \(x+2y=6\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Choose convenient values of one variable and calculate the other using \(x=6-2y\).
✏️ Step-by-Step Solution
  1. For \(y=0\), \(x=6\), giving \((6,0)\).
  2. For \(y=1\), \(x=4\), giving \((4,1)\).
  3. For \(y=2\), \(x=2\), giving \((2,2)\).
  4. For \(y=3\), \(x=0\), giving \((0,3)\).
  5. Substitution verifies each ordered pair.
✅ Final Answer
Four solutions are \(\boxed{(6,0),(4,1),(2,2),(0,3)}\).
🌐 Gujarati Translation — Final Answer
ચાર ઉકેલો: \((6,0),(4,1),(2,2),(0,3)\).
📋 Given
Find two solutions for each equation:
(i) \(4x+3y=12\); (ii) \(2x+5y=0\); (iii) \(3y+4=0\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Select values that make the remaining variable easy to calculate and check by substitution.
✏️ Step-by-Step Solution
  1. (i) \(x=0\Rightarrow y=4\); \(y=0\Rightarrow x=3\).
  2. (ii) \(x=0\Rightarrow y=0\); \(x=5\Rightarrow y=-2\).
  3. (iii) \(y=-\frac43\), while \(x\) is arbitrary; choose \(x=0\) and \(x=1\).
✅ Final Answer
(i) \((0,4),(3,0)\); (ii) \((0,0),(5,-2)\); (iii) \((0,-\frac43),(1,-\frac43)\).
🌐 Gujarati Translation — Final Answer
અંતિમ જવાબ ઉપરના ક્રમમાં દર્શાવ્યા છે.

Exercise 4.1Writing linear equations

📋 Given
The cost of a notebook is twice the cost of a pen. Write a linear equation in two variables to represent this statement. Take the cost of a notebook as \(₹x\) and the cost of a pen as \(₹y\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Translate “notebook cost is twice pen cost” directly into an algebraic relation.
✏️ Step-by-Step Solution
  1. Notebook cost \(=x\).
  2. Pen cost \(=y\).
  3. Twice the pen cost is \(2y\).
  4. Therefore \(x=2y\), or \(x-2y=0\).
✅ Final Answer
\(\boxed{x-2y=0}\).
🌐 Gujarati Translation — Final Answer
\(\boxed{x-2y=0}\).
📋 Given
Give the form \(ax+by+c=0\) for each equation and indicate \(a,b,c\):
(i) \(2x+3y=9.35\); (ii) \(x-\frac{y}{5}=10\); (iii) \(-2x+3y=6\); (iv) \(x=3y\); (v) \(2x=-5y\); (vi) \(3x+2=0\); (vii) \(y-2=0\); (viii) \(5=2x\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Bring every term to the left and compare with \(ax+by+c=0\).
✏️ Step-by-Step Solution
  1. (i) \(2x+3y-9.35=0\): \((a,b,c)=(2,3,-9.35)\).
  2. (ii) \(x-\frac15y-10=0\): \((1,-\frac15,-10)\).
  3. (iii) \(-2x+3y-6=0\): \((-2,3,-6)\).
  4. (iv) \(x-3y=0\): \((1,-3,0)\).
  5. (v) \(2x+5y=0\): \((2,5,0)\).
  6. (vi) \(3x+0y+2=0\): \((3,0,2)\).
  7. (vii) \(0x+y-2=0\): \((0,1,-2)\).
  8. (viii) \(2x+0y-5=0\): \((2,0,-5)\).
✅ Final Answer
All standard forms and coefficients are listed above.
🌐 Gujarati Translation — Final Answer
બધા પ્રમાણભૂત સ્વરૂપો અને ગુણાંકો ઉપર દર્શાવ્યા છે.

Exercise 4.2Solutions of linear equations

📋 Given
Which one of the following options is true, and why? \(y=3x+5\) has (i) a unique solution, (ii) only two solutions, or (iii) infinitely many solutions.
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
A linear equation in two variables has infinitely many ordered-pair solutions unless additional independent information is given.
✏️ Step-by-Step Solution
  1. Rewrite as \(3x-y+5=0\), a linear equation in two variables.
  2. For every real value chosen for \(x\), the value \(y=3x+5\) is determined.
  3. For example, \(x=0,1,2\) give \((0,5),(1,8),(2,11)\).
  4. Since infinitely many real values of \(x\) may be chosen, there are infinitely many solutions.
✅ Final Answer
Option (iii): \(\boxed{\text{infinitely many solutions}}\).
🌐 Gujarati Translation — Final Answer
વિકલ્પ (iii): અનંત ઉકેલો.
📋 Given
Write four solutions for each equation:
(i) \(2x+y=7\); (ii) \(\pi x+y=9\); (iii) \(x=4y\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Choose convenient values of one variable and calculate the other.
✏️ Step-by-Step Solution
  1. (i) \(y=7-2x\): choose \(x=0,1,2,3\), giving \((0,7),(1,5),(2,3),(3,1)\).
  2. (ii) \(y=9-\pi x\): choose \(x=0,1,2,-1\), giving \((0,9),(1,9-\pi),(2,9-2\pi),(-1,9+\pi)\).
  3. (iii) \(x=4y\): choose \(y=0,1,2,-1\), giving \((0,0),(4,1),(8,2),(-4,-1)\).
✅ Final Answer
The four solution sets are given above.
🌐 Gujarati Translation — Final Answer
ચારેય ઉકેલ સમૂહો ઉપર દર્શાવ્યા છે.
📋 Given
Check which ordered pairs satisfy \(x-2y=4\):
(i) \((0,2)\); (ii) \((2,0)\); (iii) \((4,0)\); (iv) \((\sqrt2,4\sqrt2)\); (v) \((1,1)\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Substitute each ordered pair and compare the left side with 4.
✏️ Step-by-Step Solution
  1. (i) \(0-2(2)=-4\ne4\): not a solution.
  2. (ii) \(2-2(0)=2\ne4\): not a solution.
  3. (iii) \(4-2(0)=4\): solution.
  4. (iv) \(\sqrt2-8\sqrt2=-7\sqrt2\ne4\): not a solution.
  5. (v) \(1-2=-1\ne4\): not a solution.
✅ Final Answer
Only \(\boxed{(4,0)}\) is a solution.
🌐 Gujarati Translation — Final Answer
માત્ર \(\boxed{(4,0)}\) ઉકેલ છે.
📋 Given
Find the value of \(k\) if \(x=2, y=1\) is a solution of \(2x+3y=k\).
🎯 To Find
Complete the required proof or calculation.
📘 Formula / Concept Used
Substitute the given ordered pair.
✏️ Step-by-Step Solution
  1. Put \(x=2\) and \(y=1\).
  2. \(k=2(2)+3(1)\).
  3. \(k=4+3=7\).
✅ Final Answer
\(\boxed{k=7}\).
🌐 Gujarati Translation — Final Answer
\(\boxed{k=7}\).
