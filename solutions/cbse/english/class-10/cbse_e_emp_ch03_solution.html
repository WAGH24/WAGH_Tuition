Session 1: Basic Computer Operations

(a) Turn on
(b) Hover
(c) Right click
(d) Drag and Drop
✅ Correct Answer: (a) Turn on
🧠 Explanation: A mouse can hover, right-click and drag-and-drop. The computer is turned on with its power button.
🌐 Gujarati Final Answer: કમ્પ્યુટર ચાલુ કરવાનું કાર્ય માઉસથી થતું નથી.
(a) Highlighting
(b) Dragging
(c) Selecting
(d) Moving
✅ Correct Answer: (b) Dragging
🧠 Explanation: Holding the left button while moving an item is called dragging.
🌐 Gujarati Final Answer: ડાબું બટન દબાવી માઉસ ખસેડવું dragging કહેવાય છે.
✅ Answer:
🧠 Explanation: Correct order: (1) Power on Self-Test (POST) starts, (2) operating system starts, (3) login screen appears, (4) welcome screen appears after successful login, and (5) desktop appears.
🌐 Gujarati Final Answer: ક્રમ: POST, ઓપરેટિંગ સિસ્ટમ, લૉગિન સ્ક્રીન, વેલકમ સ્ક્રીન, ડેસ્કટોપ.
✅ Answer:
🧠 Explanation: The ENTER key confirms a command or selection, moves the cursor to a new line in text and submits information in many forms or dialog boxes.
🌐 Gujarati Final Answer: ENTER કી આદેશ સ્વીકારે છે, નવી લીટી શરૂ કરે છે અને ફોર્મ સબમિટ કરે છે.
✅ Answer:
🧠 Explanation: Create a strong password-protected user account, lock the screen whenever you leave, do not share the password and use separate accounts with limited permissions for other users.
🌐 Gujarati Final Answer: મજબૂત પાસવર્ડ, સ્ક્રીન લૉક અને અલગ વપરાશકર્તા ખાતાથી અન્યનો અનધિકૃત ઉપયોગ અટકાવી શકાય.

Session 2: Performing Basic File Operations

(a) Ctrl + C
(b) Ctrl + P
(c) Ctrl + V
(d) Ctrl + X
✅ Correct Answer: (c) Ctrl + V
🧠 Explanation: Ctrl + V pastes copied or cut content.
🌐 Gujarati Final Answer: પેસ્ટ માટે Ctrl + V વપરાય છે.
(a) .jpg
(b) .doc
(c) .text
(d) .txt
✅ Correct Answer: (d) .txt
🧠 Explanation: Plain text files created in Notepad commonly use the .txt extension.
🌐 Gujarati Final Answer: નોટપેડ ફાઇલનું સામાન્ય એક્સ્ટેન્શન .txt છે.
(a) Ctrl + X
(b) Ctrl + C
(c) Ctrl + Z
(d) Ctrl + Y
✅ Correct Answer: (b) Ctrl + C
🧠 Explanation: Ctrl + C copies selected content.
🌐 Gujarati Final Answer: કૉપી માટે Ctrl + C વપરાય છે.
✅ Answer:
🧠 Explanation: Both systems organise information in a hierarchy. Computer folders are like cabinets or school folders, files are like individual documents, names and locations help retrieval, and items can be created, copied, moved, renamed or deleted.
🌐 Gujarati Final Answer: કમ્પ્યુટર ફોલ્ડર કબાટ/ફાઇલ સમાન અને ડિજિટલ ફાઇલ દસ્તાવેજ સમાન છે; બંને માહિતી ગોઠવીને શોધવામાં મદદ કરે છે.
✅ Answer:

🌐 Gujarati Final Answer: ટેક્સ્ટ એડિટરમાં લખાણ લખીને File > Save, ફોલ્ડર, નામ અને Save પસંદ કરો.

Session 3: Computer Care and Maintenance

(a) It can break
(b) It can stop functioning
(c) It can overheat
(d) Data can get corrupt
✅ Correct Answer: (c) It can overheat
🧠 Explanation: Continuous charging may generate unnecessary heat and reduce battery health.
🌐 Gujarati Final Answer: પૂર્ણ ચાર્જ પછી જોડેલું રાખવાથી ઉપકરણ ગરમ થઈ શકે છે.
(a) Protect it from overheating
(b) Increase its performance
(c) Prevent data from getting corrupt
(d) Back up data
✅ Correct Answer: (c) Prevent data from getting corrupt
🧠 Explanation: Antivirus detects and removes malicious software that can damage or corrupt data.
🌐 Gujarati Final Answer: એન્ટીવાયરસ હાનિકારક સોફ્ટવેરથી ડેટાને નુકસાન થતું અટકાવે છે.
(a) Keep the device unplugged when in use
(b) Do not cover a laptop with a blanket
(c) Make sure the CPU fan is working
(d) Avoid leaving the device in the sun
✅ Correct Answer: (a)
🧠 Explanation: A device does not always need to be unplugged while in use. Proper ventilation and avoiding heat sources are essential.
🌐 Gujarati Final Answer: ઉપયોગ દરમિયાન હંમેશા ઉપકરણ અનપ્લગ રાખવું જરૂરી નથી.
(a) Turn it upside down and shake gently
(b) Blow out dust with a blower
(c) Clean stains with a very dilute soap-water solution on a non-abrasive cloth
(d) All of the above
✅ Correct Answer: (d) All of the above
🧠 Explanation: All listed methods can help when done carefully and with the device switched off.
🌐 Gujarati Final Answer: બધી રીતો સાવધાનીથી અપનાવી શકાય છે.
✅ Answer:
🧠 Explanation: Switch off and unplug the computer. Wipe the screen and outer surfaces with a soft dry or slightly damp lint-free cloth, remove keyboard dust gently, keep vents clear, keep food and liquids away, tidy cables and ensure the area is dry and well ventilated. Never spray liquid directly on the device.
🌐 Gujarati Final Answer: કમ્પ્યુટર બંધ કરી નરમ કપડાથી સાફ કરો, કીબોર્ડ અને વેન્ટમાંથી ધૂળ દૂર કરો અને પ્રવાહી સીધું ન છાંટો.
✅ Answer:
🧠 Explanation: Remove unnecessary files and programs, keep adequate free storage, update the operating system and antivirus, scan for malware, close unused applications, clear temporary files, restart periodically and maintain proper cooling. Hardware upgrades such as more RAM may help when required.
🌐 Gujarati Final Answer: અનાવશ્યક ફાઇલ/પ્રોગ્રામ દૂર કરો, અપડેટ અને સ્કેન કરો, એપ બંધ કરો, ઠંડક રાખો અને જરૂર પડે તો RAM વધારો.

Session 4: Computer Security and Privacy

(a) Lock your computer
(b) Give card or bank details only on safe websites
(c) Use antivirus
(d) Do not use pirated software
✅ Correct Answer: (b)
🧠 Explanation: Sensitive payment information should be entered only on trusted, secure websites with valid HTTPS protection.
🌐 Gujarati Final Answer: બેંક/કાર્ડ વિગતો માત્ર સુરક્ષિત અને વિશ્વસનીય વેબસાઇટ પર આપવી.
(a) Online predators
(b) Worms
(c) Trojan Horse
(d) Antivirus
✅ Correct Answer: (a) Online predators
🧠 Explanation: Online predators are people who misuse digital communication to manipulate or exploit children.
🌐 Gujarati Final Answer: ઑનલાઇન પ્રેડેટર બાળકોને અયોગ્ય સંબંધમાં ફસાવી શકે છે.
(a) Only letters
(b) Numbers and special characters
(c) A person’s name
(d) Letters, numbers and special characters
✅ Correct Answer: (d)
🧠 Explanation: A strong password combines upper- and lowercase letters, numbers and special characters and should be unique.
🌐 Gujarati Final Answer: મજબૂત પાસવર્ડમાં અક્ષરો, આંકડા અને વિશેષ ચિહ્નો હોવા જોઈએ.
✅ Answer:
🧠 Explanation: A Trojan disguises itself as useful or harmless software. When the user installs or opens it, the malicious code may steal information, damage files, create a backdoor or give an attacker remote access. Unlike a worm, it usually depends on the user being deceived into running it.
🌐 Gujarati Final Answer: ટ્રોજન ઉપયોગી સોફ્ટવેર જેવું દેખાઈ વપરાશકર્તાથી ખૂલ્યા પછી ડેટા ચોરી, નુકસાન અથવા અનધિકૃત પ્રવેશ કરે છે.
✅ Answer:
🧠 Explanation: Use strong unique passwords and two-factor authentication, keep software and antivirus updated, back up important files, avoid suspicious links and attachments, use secure networks and websites, set proper privacy permissions, encrypt sensitive data, lock devices and never share confidential information unnecessarily.
🌐 Gujarati Final Answer: મજબૂત પાસવર્ડ, 2FA, અપડેટ, બેકઅપ, સુરક્ષિત નેટવર્ક, ગોપનીયતા સેટિંગ અને શંકાસ્પદ લિંકથી બચવું.
